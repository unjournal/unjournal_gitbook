# Drop-in slides

Slides for The Unjournal's open monthly drop-ins, one HTML file per session (`YYYY-MM-DD.html`).
Served at https://uj-dropin-slides.netlify.app/ ; the root redirects to the latest session (see `netlify.toml`).

Open-session content only. Management-segment slides never go here (they hold funding detail and stay private).

Keys: arrows/space move, N toggles speaker notes, T hides the timer for screen sharing.

Deploy from this folder:

    npx netlify-cli deploy --prod --dir=.
